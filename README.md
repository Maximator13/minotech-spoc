# MinOtech SPOC : site (aperçu)

Ce dépôt ne contient que le site statique du projet MinOtech SPOC (IMT Mines Alès × CEA Marcoule),
déployé sur Vercel ; il sert de sauvegarde du site publié. Il est généré depuis le projet source par `tools/publish.py` : ne pas modifier les fichiers ici,
ils sont écrasés à chaque publication.

Statut : aperçu non indexé via la balise `noindex, nofollow` présente dans chaque page.
Le fichier `robots.txt` autorise l'exploration, sinon les robots ne verraient pas cette balise.

Site en ligne (déployé sur Vercel) : https://minotech-spoc.vercel.app/
